02 · Agentic AI + LangGraph

Business Analyst Agent

github.com/Abdullah-Alroumi/business-analyst-agent

A LangGraph agent that finds its tools at runtime over MCP, ingests new invoices, and answers spend questions in Arabic or English. It pauses for human approval before any database write. وكيل مبني بـ LangGraph يكتشف أدواته أثناء التشغيل عبر MCP، ويدخل الفواتير الجديدة، ويجيب عن أسئلة المصروفات بالعربية أو الإنجليزية. ويتوقف لطلب موافقة الإنسان قبل أي كتابة في قاعدة البيانات.

Engineering decisionsقرارات هندسية
  • Custom StateGraph: approval triggers only for writes, read-only analysis runs freely
  • Six parallel writes are approved in one step, not six
  • Rejected actions become explicit tool messages, so the agent finishes without retrying
  • Tool-round budget and recursion limit stop runaway loops and cost
  • Report recipe comes from the server's MCP prompt
  • StateGraph مخصص: الموافقة مطلوبة لعمليات الكتابة فقط، والتحليل للقراءة يعمل بحرية
  • ست عمليات كتابة متوازية تُعتمد بموافقة واحدة، وليس ست موافقات
  • الإجراء المرفوض يصل للوكيل كرسالة صريحة، فيكمل عمله دون إعادة المحاولة
  • حد لعدد جولات الأدوات يمنع الحلقات المفتوحة ويضبط التكلفة
  • طريقة إعداد التقرير تأتي من قالب MCP على الخادم
Tested end to end against the real MCP server, with a scripted model, so tests need no API key. مختبر من البداية للنهاية مع خادم MCP الحقيقي ونموذج مبرمج، فلا تحتاج الاختبارات مفتاح API.

03 · Geospatial AI + Data Engineering

National Urban Intelligence (NUI)

github.com/Abdullah-Alroumi/national-urban-intelligence

An independent research platform that measures how well Riyadh residents can walk to public transport. Slice 1 answers one question with open data: who lives within a 600 m walk of a metro station? منصة بحثية مستقلة تقيس سهولة وصول سكان الرياض مشياً إلى النقل العام. الشريحة الأولى تجيب عن سؤال واحد من بيانات مفتوحة: من يسكن على بُعد 600 م مشياً من محطة مترو؟

Population is modeled (Kontur 2023); walking distance uses straight line × 1.3 until a pedestrian network is added. Every number is labelled observed, derived or modeled. Independent research, not an official platform. السكان تقديريون (Kontur 2023)، والمسافة محسوبة بخط مستقيم × 1.3 حتى تُضاف شبكة المشاة. كل رقم موسوم بنوعه: مرصود أو مشتق أو تقديري. مشروع بحثي مستقل، وليس منصة رسمية.

Engineering decisionsقرارات هندسية
  • Data feasibility study before any code: 16 sources checked for access, license and freshness
  • Every source pinned by SHA-256 and verified on each run
  • Found and fixed real data issues: 20 broken district polygons, interchange stations listed per line
  • Multi-source Dijkstra on the OSM walk graph, with a documented euclidean fallback
  • Two population releases compared: headline stable at ~6%
  • دراسة جدوى للبيانات قبل كتابة أي كود: فحص 16 مصدراً من حيث الإتاحة والترخيص والحداثة
  • كل مصدر مثبت ببصمة SHA-256 ويُتحقق منه في كل تشغيل
  • اكتشاف وإصلاح مشكلات حقيقية: 20 حياً بحدود تالفة، ومحطات تحويل مكررة لكل مسار
  • خوارزمية Dijkstra متعددة المصادر على شبكة المشاة، مع بديل موثّق بالخط المستقيم
  • مقارنة إصدارين لبيانات السكان: النتيجة الرئيسية ثابتة عند نحو 6%
